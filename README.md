## ✏️ วิธีแก้เกม (ที่เครื่องนี้)

ต้องติดตั้ง **Git** ก่อน → ดาวน์โหลดที่ https://git-scm.com

**ครั้งแรก — ดึงโปรเจกต์ลงเครื่อง:**
```bash
git clone https://github.com/tac29ad1-blip/math-quiz-p5.git
cd math-quiz-p5
```

**ทุกครั้งที่จะแก้:**
```bash
git pull                        # 1) ดึงเวอร์ชันล่าสุดก่อนเสมอ (สำคัญมาก กันงานชนกัน)
#   2) แก้ไฟล์ index.html  (เปิดด้วย VS Code หรือโปรแกรมแก้ข้อความ)
git add -A
git commit -m "บอกสั้นๆ ว่าแก้อะไร"
git push                        # 3) ส่งขึ้น → เว็บอัปเดตเองใน ~1 นาที
```

- ตอน `git push` ครั้งแรกจะให้ **login GitHub** (เด้งเบราว์เซอร์ให้ยืนยัน) — ทำครั้งเดียว เครื่องจะจำไว้
- **อยากลองดูเกมก่อน push:** ดับเบิลคลิกเปิด `index.html` ในเบราว์เซอร์ได้เลย

## 🔁 กฎเหล็ก กัน "งานชนกัน" (แก้จากหลายเครื่อง)

1. **`git pull` ทุกครั้งก่อนเริ่มแก้**
2. แก้เสร็จ `commit` + `push` ทันที อย่าค้างไว้นาน
3. อย่าแก้ไฟล์เดียวกันสองเครื่องพร้อมกันโดยไม่ pull ก่อน

> ถ้า push แล้วถูกปฏิเสธ (rejected) เพราะมีคน push มาก่อน ให้ `git pull` ก่อนแล้วค่อย `push` ใหม่
